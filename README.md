- README.md — publishing instructions

## Important: connect real order submissions
The website is intentionally configured with the placeholder:
https://formspree.io/f/YOUR_FORM_ID

### Recommended setup: Formspree
1. Go to https://formspree.io/
2. Create an account.
3. Create a new form.
4. Add the email address where you want client orders delivered.
5. Copy the Form Endpoint.
6. Open index.html.
7. Replace the YOUR_FORM_ID endpoint with your real Formspree endpoint.
8. Save and upload all files.

## Publishing with GitHub Pages
1. Open repository Settings.
2. Open Pages.
3. Select the main branch and root folder.
4. Save. GitHub will provide the website address.
